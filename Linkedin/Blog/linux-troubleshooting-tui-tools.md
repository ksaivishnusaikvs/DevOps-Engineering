# Linux Troubleshooting with TUI Tools

**Logs • System Health • Disk**

## Problem

While troubleshooting Linux servers, I was switching between different commands to check logs, services, CPU, memory, and disk usage.

It was taking more time than I wanted.

## How I Debugged It

I started using a few **TUI (Terminal User Interface) tools** to get a quick view of what was happening on the server.

This made it easier to check:

- Logs
- CPU & memory
- Disk usage
- System health
- Running processes

## Solution

TUI tools helped me find service errors and resource issues faster.

Instead of switching between many commands, I could see important information in one place.

### Simple Workflow

**Linux Issue → Check Logs & System Health → TUI Tools → Identify the Problem → Fix**

## What I Learned

The right TUI tools can make Linux troubleshooting **faster, simpler, and easier to understand**.
