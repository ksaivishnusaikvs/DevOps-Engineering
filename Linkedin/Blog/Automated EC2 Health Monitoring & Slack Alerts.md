## Context

Managing multiple EC2 instances makes manual health checks time-consuming.

I built a simple automated monitoring solution that checks:

- EC2 instance health
- CPU utilization
- Memory utilization
- Disk utilization

When an issue is detected, the system automatically sends an alert to **Slack**.

This helps identify EC2 problems faster and reduces the need for repeated manual monitoring.
