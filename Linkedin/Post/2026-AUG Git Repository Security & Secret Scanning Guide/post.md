# Git Repository Security 🔐

**A single Git commit can become a security risk.**

It's easy to accidentally commit an API key, password, or token while working on a project. But that one small mistake can lead to serious security issues.

While learning about Git repository security, I explored how secret scanning helps identify sensitive information before it reaches production.

**One thing I learned:**

**Security doesn't begin after deployment. It begins before every commit.**

**Scan → Review → Commit → Push**

Small security checks today can prevent major problems tomorrow.
